# The Green Thumb Journal - Plant Management System (Ex. No. 12)

React.js frontend, Node.js + Express.js backend, MongoDB database.

## Run (MongoDB must be running)

Terminal 1 - backend
```
cd backend
npm install
node server.js
```

Terminal 2 - frontend
```
cd frontend
npm install
npm run dev
```
Open the URL shown by Vite (usually http://localhost:5173).

## Question 5 version (plant code + search by type)
Copy `q5/backend/server.js` over `backend/server.js` and
`q5/frontend/src/App.jsx` over `frontend/src/App.jsx`, then restart the backend.
